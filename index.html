Education & Content

  1. Go Concurrency

    Starts on November 30th, 2026

    This course takes you from goroutines and channels, through coordination and synchronization, to the memory model, atomics, lock-free techniques, profiling, and production architecture.

    It is not a catalog of APIs. It is a model of who runs the work, who owns the state, who waits for whom, what establishes happens-before, how work stops, and how you measure that.

    The text assumes Go 1.23 or later in the go line of go.mod, and it notes where Go 1.25 changes the default GOMAXPROCS. When behavior depends on a version, that version is stated. Scheduler details outside the specification are a model of the runtime. They are not a contract of the language.

  2. GoPath – Zero to Gopher

    The course takes you from the first program to services, tests, concurrency, secure code, profiling, and tools around the Go ecosystem. Each lesson explains the mechanism, shows code, and breaks down the decision: why Go works exactly that way and what trade-off that decision carries.

    The target language version is Go 1.22+. Where a lesson depends on a newer API, that is noted in the text itself.

    The course has 227 lessons in three modules: 01-Basics, 02-Intermediate, and 03-Others. The basics are areas 01 through 08.

  4. Go Testing Handbook

    This course contains a comprehensive tutorial dedicated to testing in the Go (Golang) programming language.

    The goal is not only to explain how to write tests, but also to explain:

    • why a particular testing technique exists,
    • when it should be used,
    • when it should be avoided,
    • and how experienced Go developers organize tests in production projects.

    The documentation gradually progresses from basic concepts to advanced topics and is intended for developers who already know the Go language and want to improve the quality of their code.

  5. Cup 'o Go: 30 Pointer days

    Cup 'o Go is a free, bite-sized course that turns Go pointers, one of the language's most misunderstood topics, into a daily habit. Over 30 days, each lesson takes about as long as a cup of coffee. Every lesson pairs a short, practical explanation with real Go code and focuses on what you'll actually meet in production codebases, not on dry theory.

    The course goes from the very basics to the low-level details, and also explains why Go's pointer rules are designed the way they do. By the end, you'll know when to reach for a pointer and when a plain value is the better choice. The result is Go code that is simpler, safer and more idiomatic.
