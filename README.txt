CODEX · SOFT — static website
==============================

Open index.html in any browser (double-click), or upload the whole folder
to your web hosting. Keep the folder structure as is. The public site is
https://codex-soft.dev/ (hyphen). Do not add a GitHub Pages CNAME here;
hosting is separate from this folder.

  index.html      Home page (Home, Skills, Experience, About, Education, Contact)
  privacy.html    Privacy Policy
  terms.html      Terms of Service
  404.html        Not-found page in the same style
  robots.txt      Crawler rules and sitemap location
  sitemap.xml     Index, privacy, and terms
  favicon.ico     Browser tab icon
  apple-touch-icon.png
  css/style.css   All styles
  js/script.js    Menu, scroll spy, expandable sections, contact dialog
  images/         Logo, portrait, background, course marks, Open Graph image
