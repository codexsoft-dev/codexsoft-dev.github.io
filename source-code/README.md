# CODEX · SOFT — CV presentation (source code)

Requirements: Node.js 20+ and npm (or Bun).

```sh
npm install
npm run dev      # local preview at http://localhost:8080
npm run build    # production build
npm test         # behaviour tests
```

- All texts, skills, jobs and courses: `src/content/portfolio.ts`
- Images: `src/assets/`
- Pages: `src/routes/` (home, privacy, terms)
